# Hangman Word Guessing Game

## Project Description

Hangman is a simple interactive, console-based word guessing game developed using Python 3 .

The objective of the game is to guess a randomly selected hidden word one letter at a time. The player has a maximum of six incorrect attempts before the game ends.

The game uses ASCII art to visually display the hangman as incorrect guesses are made.

## Features

-Random selection of secret words.

-Letter-by-letter word guessing.

-Maximum of six incorrect attempts.

-ASCII hangman graphics that update after incorrect guesses.

-Displays correctly guessed letters.

-Tracks previously guessed letters.

-Prevents duplicate guesses from deducting additional attempts.

-Input validation to ensure only one alphabetic character is entered.

-Displays victory and defeat messages.

## How to Run the Game

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command: python hangman.py
5. Press Enter to start playing.

## How to Play

1. Run the program to start the game.
2. The computer randomly selects a hidden word.
3. Enter one letter at a time to guess the word.
4. Correct guesses reveal the corresponding letters.
5. Incorrect guesses update the hangman drawing.
6. Repeated guesses do not deduct additional attempts.
7. Guess the complete word before using all six incorrect attempts to win.
8. If you make six incorrect guesses, the game ends.

## Game Outcome

The game has two possible outcomes:

**Victory:** The player successfully guesses all the letters in the hidden word.

**Defeat:** The player makes six incorrect guesses without completing the word.
